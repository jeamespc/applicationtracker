How this works

Your edits save automatically to this browser (localStorage), tied to this file. Use Export backup occasionally so you have a copy outside the browser — especially before clearing browser data or switching machines.

Fit tier (carried over from The List)

Ready to Apply — top of the list, apply first.
Applied — already sent, waiting to hear back.
Strong Fit — good match, not yet contacted.
Different Angle — adjacent/backup option, not a core studio fit.
Rejected — not pursuing. Onsitestudio is pre-filled here from the original doc, but its own note flags open slots and a toolkit match, so it's worth a second look before fully closing that door.

Suggested workflow per studio

  • Confirm the contact or posting is still live.
  • Pick portfolio pieces to feature, using the "Why It Fits" note as a guide.
  • Tailor your CV and a short intro email or website application.
  • Send — set Status to "Applied", fill Date Applied, set Follow-up Date (~2 weeks out).
  • On response, update Status and log it in Response Log.
  • Check the "Follow-ups due" stat at the top when you open this page — that's your action list.

Some Location, Team Size and Contact fields are blank where the original notes didn't specify — confirm before applying rather than assuming.
